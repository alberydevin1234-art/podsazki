# Сайт «Подсказки для поступления на службу»

Каталог файлов по организациям (ФСБ, ФСИН, ППС, ГАИ, ЕСС) с поиском, счётчиком скачиваний и входом для публикаторов.

## Роли
- **Посетители** — смотрят список, ищут и скачивают файлы. Вход не нужен.
- **Публикатор** (логин по умолчанию `nexus`) — может только добавлять материалы.
- **Владелец** (необязательно) — может добавлять и удалять материалы.

Пароли в код **не записаны**: они задаются переменными окружения.

## Запуск на своём компьютере
Нужен Node.js 18+.

    npm install
    # Linux / macOS:
    PUBLISHER_PASS="ваш_пароль" OWNER_PASS="пароль_владельца" npm start
    # Windows (PowerShell):
    $env:PUBLISHER_PASS="ваш_пароль"; $env:OWNER_PASS="пароль_владельца"; npm start

Откройте http://localhost:3000

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `PUBLISHER_PASS` | пароль публикатора (обязательно) |
| `PUBLISHER_USER` | логин публикатора (по умолчанию `nexus`) |
| `OWNER_PASS` | пароль владельца (рекомендуется) |
| `OWNER_USER` | логин владельца (по умолчанию `owner`) |
| `SECRET` | длинная случайная строка для подписи входа (чтобы вход не сбрасывался при перезапуске) |
| `DATA_DIR` | папка для файлов и базы (по умолчанию `./data`) |

## Как выложить на GitHub
1. Создайте репозиторий на github.com.
2. Загрузите в него все файлы из этой папки (папки `node_modules` и `data` не нужны, `.gitignore` их исключает).

**Важно:** GitHub Pages размещает только статические страницы и не умеет запускать серверы, поэтому этот сайт на Pages не заработает. GitHub хранит код, а запускать сайт нужно на сервисе с поддержкой Node.js.

## Как запустить сайт из GitHub (например, на Render)
1. На render.com: **New → Web Service**, подключите репозиторий.
2. Build Command: `npm install`. Start Command: `npm start`.
3. В разделе Environment добавьте `PUBLISHER_PASS`, `OWNER_PASS`, `SECRET`.
4. Чтобы загруженные файлы не пропадали при перезапуске, подключите **Disk** (платная функция), примонтируйте его, например, в `/var/data` и задайте `DATA_DIR=/var/data`. На бесплатном тарифе без диска файлы после перезапуска исчезают.

Подойдут и аналогичные сервисы: Railway, Fly.io, любой VPS с Node.js.
